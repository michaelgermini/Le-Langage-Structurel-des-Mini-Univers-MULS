# 7.4 Génération de mini-univers simulés

## L'usine à univers du MULS

La **génération de mini-univers simulés** est l'une des capacités les plus puissantes du MULS. Au lieu de décrire manuellement chaque univers, le système peut **créer automatiquement** des configurations valides selon des critères spécifiés.

Cette fonctionnalité transforme le MULS d'un langage descriptif en un **outil de recherche et d'exploration** capable de générer des milliers d'univers candidats pour tester des hypothèses physiques.

## Principes de génération

### Approches de génération

**Aléatoire contraint** : Génération probabiliste respectant les règles
**Évolutionnaire** : Optimisation par algorithmes génétiques
**Template-based** : Construction à partir de modèles existants
**Rule-based** : Application de règles de transformation

### Contraintes de base

**Validité** : Tout univers généré doit être syntaxiquement et sémantiquement correct
**Cohérence** : Respect des invariants topologiques
**Pertinence** : Adéquation aux critères de recherche
**Diversité** : Exploration d'espaces différents

## Générateur aléatoire contraint

### Architecture de base

```python
class MULSUniverseGenerator:
    def __init__(self, constraints=None):
        self.constraints = constraints or {}
        self.random_seed = None

    def generate(self, signature=None):
        """Génère un univers selon la signature donnée"""
        if not signature:
            signature = self.generate_random_signature()

        universe = MULSUniverse(signature)

        # Générer les morphs
        morphs = self.generate_morphs(signature)
        for morph in morphs:
            universe.add_morph(morph)

        # Générer les relations
        relations = self.generate_relations(morphs)
        for relation in relations:
            universe.add_relation(relation)

        # Valider et corriger si nécessaire
        if not universe.validate():
            universe = self.repair_universe(universe)

        return universe
```

### Génération de signatures

```python
def generate_random_signature(self):
    """Génère une signature aléatoire valide"""
    # Distribution réaliste basée sur la physique connue
    ns = self.random_choice([1, 2, 3, 4, 5, 6, 8, 12, 16], weights=[0.1, 0.15, 0.2, 0.15, 0.1, 0.1, 0.05, 0.03, 0.02])
    nb = self.random_choice([0, 1, 2, 3], weights=[0.4, 0.3, 0.2, 0.1])
    nc = self.random_choice([0, 1, 2, 3, 6, 7], weights=[0.2, 0.2, 0.2, 0.15, 0.15, 0.1])

    # Deff doit être ≥ 4
    deff = self.random_choice([4, 5, 6, 10], weights=[0.6, 0.2, 0.1, 0.1])

    # χ calculé ou estimé
    chi = self.estimate_euler_characteristic(ns, nb, nc, deff)

    return MULSSignature(ns, nb, nc, deff, chi)
```

### Génération de morphs

```python
def generate_morphs(self, signature):
    """Génère les morphs selon la signature"""
    morphs = []

    # Générer les cordes
    for i in range(signature.ns):
        morph = self.generate_string_morph(i)
        morphs.append(morph)

    # Générer les branes
    for i in range(signature.nb):
        morph = self.generate_brane_morph(i)
        morphs.append(morph)

    # Générer les dimensions compactifiées
    for i in range(signature.nc):
        morph = self.generate_compact_morph(i)
        morphs.append(morph)

    return morphs

def generate_string_morph(self, index):
    """Génère une corde avec propriétés réalistes"""
    # Propriétés physiques typiques
    mass = self.random_log_normal(0.1, 2.0)  # Masses entre 0.1 et 2 GeV
    charge = self.random_choice([-1, 0, 1, 2/3, -1/3], weights=[0.2, 0.3, 0.2, 0.15, 0.15])
    spin = self.random_choice([0, 0.5, 1], weights=[0.1, 0.8, 0.1])

    properties = {
        'mass': mass,
        'charge': charge,
        'spin': spin
    }

    # Ajouter des propriétés spécifiques si nécessaire
    if self.constraints.get('include_frequency', False):
        properties['frequency'] = self.random_normal(440, 100)

    return MULSMorph(f'string_{index}', 'S', properties)
```

### Génération de relations

```python
def generate_relations(self, morphs):
    """Génère les relations entre morphs"""
    relations = []

    # Grouper par type
    strings = [m for m in morphs if m.type == 'S']
    branes = [m for m in morphs if m.type == 'B']
    compacts = [m for m in morphs if m.type == 'C']

    # Cordes → Branes (confinement)
    for string in strings:
        if branes and self.random_bool(0.8):  # 80% de chance
            brane = self.random_choice(planes)
            relations.append(MULSRelation(
                string.id, brane.id,
                'confinement',
                {'strength': self.random_uniform(0.5, 1.0)}
            ))

    # Cordes → Dimensions compactifiées (modulation)
    for string in strings:
        if compacts:
            compact = self.random_choice(compacts)
            relations.append(MULSRelation(
                string.id, compact.id,
                'modulation',
                {'amplitude': self.random_uniform(0.1, 1.0)}
            ))

    # Relations entre branes si multiples
    for i, brane1 in enumerate(planes):
        for brane2 in planes[i+1:]:
            if self.random_bool(0.3):  # 30% de chance
                relations.append(MULSRelation(
                    brane1.id, brane2.id,
                    'intersection',
                    {'angle': self.random_uniform(0, 3.14159)}
                ))

    return relations
```

## Générateur évolutionnaire

### Algorithme génétique

```python
class EvolutionaryGenerator:
    def __init__(self, population_size=100, generations=50):
        self.population_size = population_size
        self.generations = generations

    def evolve_universes(self, fitness_function, constraints):
        """Évolution d'une population d'univers"""
        # Initialisation
        population = [self.generate_random_universe(constraints)
                     for _ in range(self.population_size)]

        for generation in range(self.generations):
            # Évaluation
            fitness_scores = [fitness_function(universe) for universe in population]

            # Sélection
            selected = self.tournament_selection(population, fitness_scores)

            # Croisement
            offspring = []
            for i in range(0, len(selected), 2):
                parent1, parent2 = selected[i], selected[i+1]
                child1, child2 = self.crossover(parent1, parent2)
                offspring.extend([child1, child2])

            # Mutation
            mutated_offspring = [self.mutate(universe) for universe in offspring]

            # Nouvelle génération
            population = selected[:self.population_size//2] + mutated_offspring

        # Retourner le meilleur
        return max(population, key=fitness_function)
```

```python
def fitness_minimal_coupling(universe):
```

### Opérateurs génétiques

```python
def crossover(self, parent1, parent2):
    """Croisement entre deux univers"""
    # Sélectionner un point de coupe
    split_point = random.randint(1, min(len(parent1.morphs), len(parent2.morphs)))

    # Combiner les morphs
    child1_morphs = parent1.morphs[:split_point] + parent2.morphs[split_point:]
    child2_morphs = parent2.morphs[:split_point] + parent1.morphs[split_point:]

    # Créer les enfants
    child1 = MULSUniverse(parent1.signature)
    child2 = MULSUniverse(parent2.signature)

    for morph in child1_morphs:
        child1.add_morph(morph)
    for morph in child2_morphs:
        child2.add_morph(morph)

    return child1, child2

def mutate(self, universe):
    """Mutation d'un univers"""
    mutated = copy.deepcopy(universe)

    mutation_type = random.choice(['add_morph', 'remove_morph', 'modify_property', 'add_relation'])

    if mutation_type == 'add_morph' and len(mutated.morphs) < 20:
        new_morph = self.generate_random_morph()
        mutated.add_morph(new_morph)

    elif mutation_type == 'remove_morph' and len(mutated.morphs) > 1:
        morph_to_remove = random.choice(mutated.morphs)
        mutated.remove_morph(morph_to_remove.id)

    elif mutation_type == 'modify_property':
        if mutated.morphs:
            morph = random.choice(mutated.morphs)
            if morph.properties:
                prop_name = random.choice(list(morph.properties.keys()))
                morph.properties[prop_name] *= random.uniform(0.5, 1.5)

    elif mutation_type == 'add_relation':
        if len(mutated.morphs) >= 2:
            morph1, morph2 = random.sample(mutated.morphs, 2)
            if self.can_relate(morph1.type, morph2.type):
                relation = self.generate_relation(morph1, morph2)
                mutated.add_relation(relation)

    return mutated
```

```python
TEMPLATES = {

            {'type': 'S', 'id': 'fundamental_string', 'properties': {'tension': 1.0}},
            # ... dimensions compactifiées
        ]
    }
}

class TemplateGenerator:
    def generate_from_template(self, template_name, variations=None):
        """Génère un univers à partir d'un template"""
        template = TEMPLATES[template_name]

        universe = MULSUniverse(template['signature'])

        # Ajouter les morphs de base
        for morph_data in template['morphs']:
            morph = MULSMorph(morph_data['id'], morph_data['type'], morph_data['properties'])
            universe.add_morph(morph)

        # Ajouter les relations de base
        for rel_data in template['relations']:
            relation = MULSRelation(
                rel_data['source'], rel_data['target'],
                rel_data['type'], rel_data.get('properties', {})
            )
            universe.add_relation(relation)

        # Appliquer les variations
        if variations:
            self.apply_variations(universe, variations)

        return universe

    def apply_variations(self, universe, variations):
        """Applique des variations au template"""
        for variation in variations:
            if variation['type'] == 'add_morph':
                morph = self.generate_morph_from_spec(variation['spec'])
                universe.add_morph(morph)
            elif variation['type'] == 'modify_property':
                morph = universe.get_morph(variation['morph_id'])
                morph.properties[variation['property']] = variation['value']
```

## Génération rule-based

### Système de règles

```python
class RuleBasedGenerator:
    def __init__(self):
        self.rules = self.load_generation_rules()

    def load_generation_rules(self):
        """Charge les règles de génération"""
        return {
            'particle_generation': {
                'condition': lambda ctx: ctx.get('has_quarks', False),
                'action': self.generate_hadrons
            },

            'symmetry_breaking': {
                'condition': lambda ctx: ctx.get('has_scalar_field', False),
                'action': self.apply_symmetry_breaking
            },

            'gauge_unification': {
                'condition': lambda ctx: len(ctx.get('gauge_groups', [])) > 1,
                'action': self.unify_gauge_groups
            }
        }

    def generate_with_rules(self, initial_universe):
        """Applique les règles itérativement"""
        universe = copy.deepcopy(initial_universe)
        context = self.analyze_context(universe)

        max_iterations = 10
        for iteration in range(max_iterations):
            applied_rules = 0

            for rule_name, rule in self.rules.items():
                if rule['condition'](context):
                    universe = rule['action'](universe, context)
                    applied_rules += 1
                    context = self.analyze_context(universe)

            if applied_rules == 0:
                break  # Convergence

        return universe

    def analyze_context(self, universe):
        """Analyse le contexte de l'univers"""
        context = {
            'has_quarks': any(m.properties.get('is_quark', False) for m in universe.morphs),
            'has_scalar_field': any(m.type == 'S' and m.properties.get('spin', 1) == 0 for m in universe.morphs),
            'gauge_groups': self.identify_gauge_groups(universe)
        }
        return context
```
