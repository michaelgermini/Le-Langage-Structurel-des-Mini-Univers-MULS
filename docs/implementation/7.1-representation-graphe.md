# 7.1 Représentation en graphe

## Les univers MULS comme réseaux mathématiques

La **représentation en graphe** constitue le cœur de l'implémentation informatique du MULS. Chaque univers est transformé en un **graphe orienté pondéré** où les morphs deviennent des nœuds et les relations deviennent des arêtes.

Cette approche permet non seulement de stocker et manipuler les structures MULS, mais aussi d'appliquer l'arsenal complet des algorithmes de théorie des graphes pour l'analyse, l'optimisation et la simulation.

## Structure graphe de base

### Nœuds (Nodes)

Chaque morph devient un nœud avec des propriétés :

**Type de nœud** : S, B, C, E, X, T
**Propriétés** : Attributs spécifiques au morph
**Identifiant unique** : Clé primaire dans le graphe

```python
class MorphNode:
    def __init__(self, node_id, morph_type, properties):
        self.id = node_id
        self.type = morph_type  # 'S', 'B', 'C', 'E', 'X', 'T'
        self.properties = properties
        self.edges = []  # Liste des arêtes connectées
```

### Arêtes (Edges)

Les relations deviennent des arêtes dirigées :

**Source/Destination** : Morphs connectés
**Type de relation** : vibration, confinement, intrication, etc.
**Propriétés** : Force, phase, portée, etc.

```python
class RelationEdge:
    def __init__(self, source_id, target_id, relation_type, properties):
        self.source = source_id
        self.target = target_id
        self.type = relation_type
        self.properties = properties
        self.weight = self.calculate_weight()
```

## Graphe orienté MULS

### Structure complète

```python
class MULSGraph:
    def __init__(self):
        self.nodes = {}  # id -> MorphNode
        self.edges = []  # Liste des RelationEdge
        self.signature = None
        self.metadata = {}

    def add_morph(self, morph_node):
        self.nodes[morph_node.id] = morph_node

    def add_relation(self, edge):
        self.edges.append(edge)
        # Mettre à jour les références dans les nœuds
        self.nodes[edge.source].edges.append(edge)
        self.nodes[edge.target].edges.append(edge)
```

### Propriétés du graphe

**Connexité** : Généralement connexe (sauf secteurs isolés)
**Orientation** : Arêtes dirigées (relations asymétriques)
**Pondération** : Poids sur les arêtes (force des relations)
**Attributs** : Propriétés sur nœuds et arêtes

import networkx as nx
import matplotlib.pyplot as plt

def visualize_muls_graph(graph):
    G = nx.DiGraph()

    # Ajouter les nœuds
    for node_id, node in graph.nodes.items():
        G.add_node(node_id, type=node.type, **node.properties)

    # Ajouter les arêtes
    for edge in graph.edges:
        G.add_edge(edge.source, edge.target,
                  type=edge.type, weight=edge.weight)

    # Positionnement et dessin
    pos = nx.spring_layout(G)
    nx.draw(G, pos, with_labels=True, node_color=node_colors)
    plt.show()
