# 5.2 Format transmissible MML

## Le langage de balisage minimal du MULS : optimisé pour la transmission

Si le format ASCII est le langage naturel du MULS, le **MML (Minimal Markup Language)** en est la version ultra-optimisée pour la **transmission fiable**, la **compression maximale** et l'**interopérabilité** dans des environnements contraints.

Le MML sacrifie la verbosité XML pour une **syntaxe minimaliste** inspirée des formats de transmission modernes, permettant des taux de compression de 10x à 15x par rapport au texte brut.

## Philosophie MML

### Ultra-légèreté

**Principe** : Le moins de caractères possible pour transmettre l'information maximale
**Inspiration** : Formats comme YAML minimal, TOML, ou les protocoles binaires modernes
**Objectif** : Transmission viable même sur les canaux les plus étroits (Morse, radio DNF)

### Syntaxe révolutionnaire

**Transformation XML → MML** :
- `<h1>Titre</h1>` → `h1:Titre`
- `<p class="intro">Texte</p>` → `p.intro:Texte`
- Attributs complexes → notation compacte avec tokens

## Structure de base

### Format canonique

```
U:SIG(3,1,2,4,2)
M:S:electron:mass=0.511|charge=-1|R:brane1:type=confinement
M:B:brane1:dimension=4|tension=1.0|R:electron:type=contains
```

### Éléments principaux

**`U:`** : Univers (Universe) - Élément racine
**`M:`** : Morph - Définition de morph
**`R:`** : Relation - Connexion entre morphs
**`#`** : Commentaire (ignoré lors du parsing)

### Tokens prédéfinis

**Types de morphs** :
- `S` : String (corde)
- `B` : Brane
- `C` : Compact (dimension compactifiée)
- `E` : Entanglement (intrication)
- `X` : Interaction (multiple)

**Propriétés communes** :
- `id` : Identifiant unique
- `mass`, `charge`, `spin` : Propriétés physiques
- `freq` : Fréquence (au lieu de `frequency`)
- `dim` : Dimension (au lieu de `dimension`)
- `topo` : Topologie (au lieu de `topology`)

## Éléments morphologiques

### Cordes (Strings)

**Format MML** :
```
M:S:electron:mass=0.511|charge=-1|spin=0.5|freq=440
R:brane1:type=confinement|strength=1.0
R:compact1:type=coupling|coupling=0.1
```

**Propriétés standards** :
- `mass`, `charge`, `spin` : Propriétés physiques
- `freq` : Fréquence (token court)
- `tension` : Tension de la corde
- Séparateur `|` entre propriétés

### Branes

**Format MML** :
```
M:B:visible_sector:dim=4|tension=1.0|charge=0|orientation=timelike
R:electron:type=contains
R:proton:type=contains
```

**Propriétés spécifiques** :
- `dim` : Dimensionalité (3-10)
- `tension` : Tension de la brane
- `orientation` : timelike/spacelike/lightlike
- `charge` : Charge totale

### Dimensions compactifiées

**Format MML** :
```
M:C:su3:radius=1.616e-35|topo=sphere|cohom=h11=1,h21=0
R:quark1:type=fundamental|mode=vibration
```

**Propriétés topologiques** :
- `radius` : Rayon de compactification
- `topo` : Type topologique (sphere, torus, calabi_yau)
- `cohom` : Classes de cohomologie
- `moduli` : Paramètres de forme

### Liens d'intrication

**Format MML** :
```
M:E:bell_pair:type=EPR|purity=0.999|fidelity=0.985
R:particle1:type=quantum_entangled|role=first
R:particle2:type=quantum_entangled|role=second
```

**Propriétés quantiques** :
- `type` : EPR, GHZ, cluster, etc.
- `purity` : Pureté de l'état (0-1)
- `fidelity` : Fidélité (0-1)
- `concurrence` : Mesure d'intrication

### Interactions multiples

**Format MML** :
```
M:X:strong_force:type=gauge|group=SU(3)|coupling=1.2
P:quark1:representation=fundamental
P:quark2:representation=fundamental
P:gluon:representation=adjoint
```

**Nouveaux éléments** :
- `P:` : Participant (au lieu de `<participant>`)
- `group` : Groupe de jauge
- `coupling` : Constante de couplage
- `representation` : Représentation des particules

## Système de relations

### Format MML

**Syntaxe compacte** :
```
R:target_id:type=relation_type|param1=value1|param2=value2
```

**Exemple** :
```
R:brane1:type=confinement|strength=1.0|phase=0
R:compact1:type=vibrational|coupling=0.8|frequency=440
```

### Types de relations

**Structurelles** :
- `confinement` : Morph confiné sur une brane
- `compactification` : Vibration sur dimension compactifiée
- `entanglement` : Connexion quantique non-locale
- `embedding` : Inclusion dans un espace supérieur

**Physiques** :
- `gauge` : Interaction de jauge
- `yukawa` : Couplage de masse
- `gravitational` : Attraction gravitationnelle
- `electromagnetic` : Interaction électromagnétique

**Topologiques** :
- `homotopy` : Classes d'homotopie
- `cohomology` : Classes de cohomologie
- `ktheory` : Classes K-théoriques
- `moduli` : Espace des paramètres

## Métadonnées et annotations

### Informations de version

**Format MML** :
```
U:SIG(3,1,2,4,2)|version=RFC-0001|created=2024-11-19|author=MULS_Consortium
```

### Commentaires et documentation

**Syntaxe** :
```
# Modèle simplifié du Standard
U:SIG(16,1,3,4,2)|desc=Modèle standard des particules avec une brane visible et trois dimensions compactifiées
```

### Références externes

**Format intégré** :
```
M:B:our_universe:dim=4|refs=arxiv:hep-th/0502058,doi:10.1103/PhysRevD.71.086004
```

**Tokens spéciaux** :
- `refs=` : Références externes
- Séparateur `,` pour plusieurs références
- Préfixes `arxiv:`, `doi:`, `url:`

## Optimisations pour la transmission

### Compression par tokens

**Dictionnaire intégré** :
- `mass` → `m`
- `charge` → `q`
- `frequency` → `f`
- `dimension` → `d`
- `tension` → `t`

**Exemple compressé** :
```
M:S:electron:m=0.511|q=-1|s=0.5|f=440
```
Au lieu de :
```
M:S:electron:mass=0.511|charge=-1|spin=0.5|frequency=440
```

### MML-Compressé (MML-C)

**Principe** : Format binaire ultra-compact

**Structure** :
```
[Header 4 bytes] [Signature 6 bytes] [Morphs compressed] [Relations compressed] [Checksum 2 bytes]
```

**Tokens binaires** :
- Types de morphs : 3 bits (0-7)
- Propriétés communes : codes 4 bits
- Valeurs numériques : encodage variable-length

**Taux de compression** : 95% vs texte ASCII

### Codes courts pour propriétés

**Mappings prédéfinis** :
```
m → mass
q → charge
s → spin
f → frequency
d → dimension
t → tension
r → radius
topo → topology
cohom → cohomology
```

**Exemple ultra-compact** :
```
U:SIG(3,1,2,4,2)
M:S:electron:m=0.511|q=-1|s=0.5|f=440|R:brane1:type=conf|t=1.0
M:B:brane1:d=4|t=1.0|R:electron:type=cont
```

## Validation et parsing

### Grammaire MML

**Règles formelles** :
```
universe ::= "U:" signature [properties]
morph ::= "M:" type ":" id ":" [properties]
relation ::= "R:" target ":" [properties]
participant ::= "P:" target ":" [properties]
comment ::= "#" text
```

### Validation automatique

**Parser MML** :
```python
def parse_mml(content):
    lines = content.strip().split('\n')
    universe = None
    morphs = {}

    for line in lines:
        line = line.strip()
        if not line or line.startswith('#'):
            continue

        if line.startswith('U:'):
            universe = parse_universe_line(line)
        elif line.startswith('M:'):
            morph = parse_morph_line(line)
            morphs[morph.id] = morph
        elif line.startswith('R:'):
            relation = parse_relation_line(line)
            # Ajouter à morph source

    return MULSUniverse(universe, list(morphs.values()))
```

**Validation sémantique** :
- Cohérence des signatures
- Existence des références
- Validité des propriétés
- Contraintes topologiques

## Conversion entre formats

### Outils de conversion

**ASCII vers MML** :
```bash
muls convert ascii-to-mml input.muls > output.mml
muls convert ascii-to-mml-c input.muls > output.mmlc  # Version compressée
```

**MML vers ASCII** :
```bash
muls convert mml-to-ascii input.mml > output.muls
muls convert mml-c-to-ascii input.mmlc > output.muls  # Depuis compressé
```

**MML vers formats spécialisés** :
```bash
muls convert mml-to-morse input.mml > output.morse    # Pour transmission DNF
muls convert mml-to-hexa input.mml > output.hexa      # Hexa-MULS
muls convert mml-to-json input.mml > output.json      # DOM-MULS
```

### Pipeline de conversion

**Chaînage automatique** :
```bash
# ASCII → MML → Morse → Transmission
cat document.muls | muls convert - | muls compress - | muls transmit -
```

### Validation de la conversion

**Test round-trip** :
```bash
muls validate --roundtrip file.muls  # Test A→MML→A
muls validate --compression file.muls  # Test A→MML-C→A
```

# Univers simple avec 2 cordes, 1 brane, 1 dimension compactifiée
U:SIG(2,1,1,4,2)|desc=Univers simple avec 2 cordes, 1 brane, 1 dimension compactifiée

M:S:electron:m=0.511|q=-1|R:visible:type=confinement
M:S:photon:m=0|q=0|R:visible:type=propagation

**Taille** : ~250 caractères vs ~800 en XML
**Compression** : 70% d'économie d'espace

## Avantages pour la transmission

### Compression révolutionnaire

**Taux records** : 8:1 à 15:1 par rapport au texte brut
**Tokens intelligents** : Mots-clés courts pour propriétés communes
**Format adaptatif** : MML standard → MML-Compressé selon les besoins

### Robustesse ultime

**Tolérance d'erreur** : Correction automatique des fautes mineures
**Streaming** : Traitement de fichiers volumineux sans mémoire excessive
**Validation temps réel** : Détection d'incohérences à la volée

### Universalité

**Tous protocoles** : Compatible avec DNF, Morse, radio, satellite
**Multi-plateformes** : Python, JavaScript, C++, embarqué
**Hors-réseau** : Fonctionne sans infrastructure internet

### Big Data structurel
